# Infinite Union — дизайн-система и руководство для Claude Code

Документ описывает, по каким правилам собран редизайн infiniteunion.com.ua. Если ты (Claude Code или разработчик) добавляешь страницу, проект в портфолио, блок или анимацию, сверяйся с этим файлом. Цель: каждое новое изменение выглядит так, будто его сделал тот же дизайнер.

---

## 0. Главные принципы

1. **Кинематографично, но без перегруза.** Один сильный эффект на экран. Если в секции уже есть движущийся объект (змея, стопка карточек, бегущий импульс), не добавляй туда второй.
2. **Тьма + красный свет.** Фон почти чёрный с тёплым подтоном, акцент — красный, который *светится* (box-shadow / text-shadow), а не просто закрашивает.
3. **Никаких шаблонных блоков.** Нельзя: карточки с иконкой-кружком сверху, «окна» с закруглённым верхом (арки), эмодзи-стикеры, градиентные кнопки, рамка с цветной полоской слева, стоковые иконки.
4. **Типографика — главный герой.** Огромные заголовки с отрицательным трекингом, контурные (outline) слова на фоне, моно-лейблы капсом.
5. **Только реальные факты.** Все цифры, цены, кейсы — только из `docs/FACTS.md` (исходный репозиторий). Никаких выдуманных отзывов, % роста, гарантий топа.
6. **SEO не жертвуем ради эффектов.** Весь текст присутствует в DOM сразу (анимации только скрывают визуально через clip-path/opacity), одна H1 на страницу, ключевые слова в H1/H2.

## 3. Глобальные слои (на каждой странице)

1. **Зерно** — fixed div, `opacity:.06; mix-blend-mode:overlay`, текстура 180×180 шума генерируется canvas'ом в `componentDidMount`.
2. **Подсветка курсора** — fixed 800×800 radial-gradient `rgba(212,0,0,.12)`, `mix-blend-mode:screen`, следует за курсором с lerp `.1`. На touch не включается.
3. **Навбар** — fixed, прозрачный; после 30–40px скролла → `rgba(10,7,6,.72)` + `backdrop-filter: blur(14px)` + нижняя линия.
4. **Прогресс-бар** (внутренние страницы) — 2px сверху, красный с glow, ширина = доля прокрутки.
5. **Футер** — 4 колонки внутренних ссылок (SEO-перелинковка) + NAP + бегущая контурная строка `INFINITE ∞ UNION`.

## 4. Анимации — каталог и точные рецепты

Все анимации выполняются в **одном rAF-цикле** (`frame(t)`), который читает `getBoundingClientRect()`. IntersectionObserver **не использовать** для элементов со скрытием через clip-path: Chrome считает обрезанный элемент невидимым, и он никогда не появится. Цикл дублируется `setInterval(…,120–150)` когда `document.hidden` (фоновые вкладки/скриншотеры).

Easing: `cubic-bezier(.76,0,.24,1)` — шторки и маски; `cubic-bezier(.23,1,.32,1)` — мягкие возвраты/hover.

| # | Эффект | Где | Рецепт |
|---|---|---|---|
| A1 | **Reveal-маска** | любые `[data-reveal]` | при setup, если элемент ниже 0.9·H: `clip-path: inset(0 0 100% 0); transform: translateY(30px)`; когда `top < 0.9·H` → `inset(-6%)` + `none`, transition 1.1s. Только для того, что ниже первого экрана. |
| A2 | **Диагональная шторка** | обёртки `[data-curtain="l|r"]` | k = smoothstep((H − top)/(0.8·H)); off = (1−k)·0.7·H; вторая сторона off·(k·1.3). `clip-path: polygon(0 Lpx,100% Rpx,100% 100%,0 100%)`. По линии среза — `[data-cline]`: 2px градиент красный→белый→красный, повёрнутый на atan2(R−L, W), opacity = sin(kπ). |
| A3 | **Световая линия секции** | `[data-line]` | width 0 → 100% за 1.4s, когда секция входит на 0.8·H. |
| A4 | **Outline → fill строки** | услуги, списки (`[data-row]`) | H3 `color:transparent; -webkit-text-stroke:1px rgba(237,232,229,.5)`. Если центр строки в ±max(h/2,60px) от центра экрана → `color:#EDE8E5; text-shadow:0 0 34px rgba(212,0,0,.55)` + верхняя линия на 100%. |
| A5 | **Запал процесса** | `[data-proc]` | вертикальная линия заполняется до 0.6·H; на конце искра (белая точка + двойной красный glow), кружки шагов, которые прошла искра, заливаются красным. |

| A8 | **Слова зажигаются** | «Наш підхід» | текст бьётся на `<span>` слов; прогресс секции → слова до индекса opacity 1, текущее слово красное с glow. |
| A9 | **Печать + прогресс** | AI-конструктор | цикл 9s: 35% печать строки, далее бар 0→100% и три строки лога по очереди. |

| A11 | **Tilt** | `[data-tilt]` | rotateY(x·14°) rotateX(−y·12°), perspective 1200; уход — 0.9s мягкий easing. |
| A12 | **Glow под курсором в карточке** | `[data-card]` | внутренний слой radial-gradient 320px в точке курсора `rgba(212,0,0,.22)`. |
| A13 | **Блик кнопки** | primary CTA | `@keyframes iuSheen` 3.4s infinite — полупрозрачная полоса через кнопку. |
| A14 | **Пульс-точка** | live-индикаторы | 7px `#ff3b2f` + glow, `iuPulse 1.8s`. |
| A15 | **Marquee** | хиро-тикер, футер | дублированный контент, `iuMq` translateX(−50%), 36–40s linear. |

### Прелоадер (главная)
Контурное слово **INFINITE** по центру; через него на 52% высоты идёт красная линия с белой огненной точкой; буквы слева от точки заливаются белым (`clip-path: inset(0 {100−p}% 0 0)` на копии слова). Снизу координаты 0.00 → 49.98° N / 36.23° E и процент. Уход — `clip-path: inset(0 0 100% 0)` 1.1s. Минимум 2s, максимум ждём GLB (fallback 6.5s). Если вкладка скрыта — сразу закрываем.

### 3D-змея (только хиро главной)
- Модель: `https://res.cloudinary.com/etdq5y69/raw/upload/v1783282631/snake3d.glb` (Draco), fallback — процедурный уроборос по лемнискате (`TubeGeometry`) через 9s или при ошибке.
- Свет: ambient 0.9, key 2.6, rim 1.4, два красных point-light (`0xd40000`) с пульсом.
- Поза = функция прогресса хиро `hp` (0→1 на высоте 175vh): desktop `x 1.05→.55, ry yaw→yaw+1.4π, s .98→.7, o 1→0`; mobile `x 0, y .62→1.1, s .66→.5`. `yaw` по умолчанию −80° (морда к зрителю), твик `snakeYaw`.
- За змеёй: радиальный красный ореол (пульс), два кольца (dashed + solid с огненной точкой) вращаются в разные стороны, горизонтальный световой штрих, контурное слово INFINITE.
- Вне хиро рендер ставится на паузу (`setPaused(true)`).
- **Нигде больше змею не использовать**, кроме 404.

## 5. Портфолио — «стопка карточек»

Самая сложная механика. Секция `#portfolio` высотой `(N·80 + 60)vh`, внутри sticky 100vh-сцена: слева `#pf-stage` (стопка), справа текст.

**Прогресс:** `prog = −rect.top / (height − H)`, `p = prog·(N + .2) − .25`, `act = floor(p)`, `f = p − act`.

**Цели карточки i:**
- в стопке (`i > act`): `x = sw·.1 + px + d·5`, `y = sh·.12 + py − d·6`, `r = pr` (случайно ±13°), `s = .7`, скрыть если глубже 5;
- активная (`i == act`): `x = −sw·.04 + sin(2πf)·16`, `y = −sh·.04 + cos(πf)·10`, `r = ar + (f−.5)·5 + clamp(vel·.25, ±9)`, `s = 1`;
- улетевшая (`i < act`): `x = −sw·1.05`, `y = −sh·.75`, `r = −24°`, `o = 0`.

**Физика:** пружина на каждую ось `v = (v + (T − x)·0.075)·(1 − 0.2); x += v` — недодемпфированная, даёт естественный «бросок» и покачивание. Наклон к курсору — отдельная пружина 0.06 / 0.82. Случайные смещения — детерминированный `rnd(i)` (sin-hash), чтобы стопка выглядела одинаково при каждой загрузке.

**z-index:** активная 50, стопка `40 − i`, улетевшие `60 + i`. Тень активной: `0 60px 120px rgba(0,0,0,.75), 0 0 0 1px rgba(255,59,47,.5), 0 0 70px rgba(212,0,0,.35)`.

**Текст справа:** все `<article data-pf-text>` лежат абсолютно друг на друге (для SEO весь текст в DOM). Активный: `opacity 1, translateY(−50%)`; остальные: `opacity 0, ±40px, blur(8px), pointer-events:none`. Индикатор — полоски `[data-pf-dot]`, активная 34px с glow. Счётчик `01 / NN`.

### Как добавить проект (пошагово)
1. **Карточка** в `#pf-stage` — один из типов:
   - *Сайт* — окно браузера: `aspect-ratio:16/11`, `width:clamp(280px,min(44vw,92vh),780px)`, `container-type:inline-size` (внутри всё в `cqw`). В окне `<img>` первого экрана, `object-fit:cover; object-position:top`. Источник: свой скриншот `assets/shot-<slug>.png` (лучше всего, 1440×990) или mShots `https://s0.wp.com/mshots/v1/<urlencoded>?w=1440&h=990&vpw=1440&vph=990` (с автоповтором, пока превью не готово). Для сайтов с прелоадером или ленивыми картинками mShots снимает недогруженный экран — тогда делай скрин вручную или собирай карточку из реальных фото сайта (пример: TRUE Bar).
   - *Бот* — «телефон»: `aspect-ratio:9/15`, `width:clamp(220px,min(25vw,46vh),400px)`, `border:5px solid #1c1c1f; border-radius:22px`, тёмная Telegram-тема (`#0e1621/#17212b/#182533/#2b5278`), внутри `[data-pf-inner]` с пузырями и кнопками — он сам прокручивается, пока карточка активна.
   - *Mini App* — как бот, но светлая тема продукта.
2. **Текст** — `<article data-pf-text>` в том же порядке: категория (моно), H3 название, лид (17–22px, fg), 3 пункта (красные точки), кнопки **«Детальніше →»** (сайт проекта, `target=_blank`) + **«Усі роботи»** (/portfolio/). Пункты на мобильном скрыты (`display:{{ pfUl }}`).
3. **Точка** `[data-pf-dot]` в индикатор.
4. Увеличь высоту секции на 80vh и обнови `01 / NN` и стат «Проєктів у портфоліо».
5. Чередуй типы карточек (сайт / бот / сайт…), чтобы стопка выглядела живой.

## 6. Универсальный шаблон `IU Page.dc.html`

### Как устроен
`fetch('content/<p>.json')` → `norm()` превращает блоки исходного сайта во view-модели → шаблон выбирает раскладку по типу блока.

| Тип блока в JSON | Раскладка | Эффекты |
|---|---|---|
| `hero` | `isHero`: крошки, пульс-лейбл, H1 (последние 1–2 слова красные), лид, CTA + «Усі ціни», статы-сетка; справа **визуал семейства** | reveal, tilt, гигантское контурное слово (ключ страницы) с параллаксом |
| `marquee` | бегущая строка | A15 |
| `pricing-tiers` / блок с `tiers` | `isTiers`: колонки тарифов; тариф с `badge` — горячий (красная рамка, градиент, glow, красная кнопка) | hover поднимает на 8px |
| `process` | `isProcess`: sticky-заголовок слева + запал справа | A5 |
| `faq` | `isFaq`: `<details>` с вращающимся «+» | — |
| `cta`, `cta-form` | `isCta`: заголовок + 4 мессенджера + форма | glow-фокус полей, блик кнопки |
| блог-статья, privacy | `isArticle`: колонка 760px, H2 с красной чертой, списки с точками, таблицы | прогресс чтения |
| всё остальное (`problem`, `cards`, `included-cards`, `portfolio`, `stats`, `content`, `pricing-table`…) | `isStd`: лейбл + H2 + абзацы, затем по наличию: таблица, статы, строки (list → outline-строки A4), карточки (h3 → сетка 1px-gap с glow под курсором A12), CTA | A1, A3, A4, A12 |

**Визуал хиро по семейству** (определяется по пути):
- `websites|constructor` → стопка из 3 окон браузера с макетом (tilt);
- `bots` → телефон с чатом IU Bot и «печатает…»;
- `ads` → дышащая гистограмма Google/Meta/TikTok;
- `seo` → поисковая строка с ключом страницы и выдача, где #1 светится;
- `platforms|ecosystems` → сетка 6×6 узлов, вспыхивающих по очереди;
- остальное (цены, портфолио, блог, EN-главная) → кольца + парящий `∞`.

Хочешь, чтобы конкретная страница была ещё уникальнее, — добавь новое семейство в `fam()` и новый `<sc-if value="{{ fam.xxx }}">` в `#hero-vis`. Правило: визуал собирается из простых форм (прямоугольники, круги, линии) + свечение, **никаких нарисованных SVG-иллюстраций**.

### Как добавить новую страницу
1. Создай `content/<key>.json` по схеме существующих (минимум: `path`, `lang`, `title`, `description`, `h1`, `keyword`, `breadcrumbs`, `blocks[]`). Блок: `{type, heading, items:[{k:'text'|'h'|'list'|'link'|'faq'|'table'|'card-link', …}]}`, `role` у текстов (`sec-label`, `hm-val`/`hm-key`, `*-num`, `*-tags`, `*-term`).
2. Добавь ключ в enum `page` (props) и ссылку в футер (`F` в `renderVals`).
3. Добавь путь в `sitemap.xml` исходного репо.
4. Проверь `?p=<key>`: H1 одна, хиро не пустой, у FAQ есть ответы.

## 6.1 3D-символы на внутренних страницах (`iu-glyph.js`)

В хиро каждой внутренней страницы — свой 3D-объект, выдавленный из векторной формы (`ExtrudeGeometry`, bevel), материалы: лицевые грани — чёрный металл (`metalness 1, roughness .24, clearcoat 1`), торцы и фаска — глянцевый красный (`#D40000`, `emissive #4a0000`). Отражения — собственное env-окружение из светящихся плоскостей (белые + красные), без внешних HDR.

| Страницы | Объект |
|---|---|
| google-ads, google-ads-search | буква **G** |
| meta-ads | **f** |
| meta-ads-instagram | камера Instagram (скруглённый квадрат + линза + точка) |
| tiktok-ads | нота TikTok + два светящихся «призрака» со смещением (красный и белый) |
| seo, seo-audit | лупа |
| seo-local | пин карты |
| bots* | бумажный самолёт Telegram |
| websites*, constructor | `</>` |
| pricing | стопка монет + подбрасываемая монета |
| platforms | кластер 3×3×3 кубов, «дышит» наружу |
| ecosystems | три сцепленных тора |
| остальное | ∞ (лемниската с красными полосами) |

Поведение: буквы и логотипы **подпрыгивают** (|sin|, сплющивание при касании «пола», красная тень на полу меняет размер), остальные парят; плавно качаются и следят за курсором; по клику — раскрутка с затуханием; три светящиеся точки бегают по орбите, к первой привязан красный point-light (бегающий блик по металлу); при скролле хиро объект поворачивается, уходит вверх и гаснет. За объектом — пульсирующий ореол и два вращающихся кольца (как у змеи на главной). Рендер на паузе, когда canvas вне экрана.

Добавить новый символ: функция `shapesFor(kind)` (массив `THREE.Shape` из `absarc`/`lineTo`/`quadraticCurveTo`, высота ~2 единицы) + правило в `kindForPath()`.

## 6.2 Переходы между страницами

- **Вуаль**: fixed-слой цвета фона с красно-белой светящейся линией по нижнему краю и названием страницы. При клике на внутреннюю ссылку (`*.dc.html`) вуаль опускается сверху за .7s, затем переход; на новой странице поднимается вверх за 1s после загрузки контента.
- **Шторки секций**: каждая секция после хиро открывается диагональным срезом со световой линией (рецепт A2), направление чередуется.
- Счётчики в статах (A7), магнитные основные кнопки (смещение к курсору ×.22/×.3), 3D-наклон карточек тарифов.

## 7. SEO-правила

- **title** ≤ 60 символов, ключ в начале: «Розробка сайтів під ключ у Харкові — веб-студія Infinite Union».
- **description** 140–160 символов, цена «від» + город + УТП.
- **H1** — одна, с главным ключом (`розробка сайтів під ключ`, `створення лендингу`, `розробка телеграм-бота` …). H2 — вторичные ключи. H3 — подуслуги / вопросы.
- canonical, hreflang uk/en/x-default, Open Graph на каждой странице.
- **schema.org** (JSON-LD в `<head>`): `ProfessionalService` (адрес Харків, geo 49.983/36.233, areaServed UA PL DE NL CZ SK GB, телефон, email, sameAs, `hasOfferCatalog` с `minPrice`), `WebSite`, `FAQPage` для каждого FAQ, `BreadcrumbList` на внутренних страницах.
- Внутренняя перелинковка: футер со всеми услугами + крошки + блок «Може зацікавити».
- Цифры-счётчики и скрытые reveal-тексты в разметке **уже финальные** — поисковик видит реальный контент.
- `alt` у всех изображений описательный («Сайт Gym4Fit — gym4fit.com.ua»).
- В JSON-LD не допускать подряд `{{` / `}}` (шаблонизатор DC) — ставь пробелы между скобками.

## 8. Мобильная версия (обязательно)

- Брейкпоинт поведения: `innerWidth < 820` → state `narrow`. Раскладки и так перестраиваются через `auto-fit minmax(min(100%,X),1fr)`; `narrow` используется только для поведения: бургер-меню на весь экран, портфолио сверху-карточка/снизу-текст (`grid-template-rows: 1.2fr 1fr`), скрытие пунктов в тексте проекта, змея по центру сверху меньшего масштаба.
- Тач: подсветка курсора и tilt выключены (`pointerType === 'touch'`).
- Hit-targets ≥ 44px (кнопки 46px+, пилюли 16–20px padding).
- Шрифты через `clamp()` — минимум 14px для текста, 10–11px только для моно-лейблов.
- Таблицы — горизонтальный скролл внутри рамки (`overflow-x:auto; min-width:560–620px`).
- Не использовать `vh` для высоты текстовых блоков (только для sticky-сцен), не `nowrap` на абзацах.
- Проверять на 360, 390, 430, 768, 1024, 1440, 1920.

## 9. Производительность

- Один rAF на страницу; записи в style только при смене состояния (кэш `_on`, `_st`).
- three.js: `pixelRatio ≤ 1.75`, пауза вне хиро.
- Картинки портфолио `loading="lazy"`.
- Большие blur/drop-shadow фильтры на крупных элементах **не анимировать** (дорого) — для свечения среза шторки используется отдельная линия, а не `filter: drop-shadow` на секции.
- `prefers-reduced-motion` (TODO при переносе в прод): отключить A2, A5-искру, физику портфолио (карточки сразу на местах), marquee.

## 10. Перенос в продакшн (статический сайт)

Текущие файлы — Design Components (дизайн-прототипы). Для боевого сайта:
1. Каждую страницу экспортировать в статический HTML (SSR/SSG) — текст должен быть в исходном HTML, а не появляться после `fetch`.
2. Ссылки вида `IU Page.dc.html?p=services__bots` → `/services/bots/`; `IU Home v2.dc.html` → `/`; `IU 404.dc.html` → `/404.html`. Обратное правило: `__` → `/`, `en__home` → `/en/`.
3. Инлайн-стили можно вынести в CSS-классы — значения токенов из раздела 2.
4. Логику `frame()` перенести в один модуль `motion.js` (функции A1–A15 + портфолио), подключать `defer`.
5. Формы → существующий бэкенд (PostgreSQL → Redis → Telegram, как в репо).
6. Скриншоты mShots заменить на свои файлы в `/assets/`.
