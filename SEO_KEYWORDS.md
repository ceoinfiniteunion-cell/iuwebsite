# Семантичне ядро Infinite Union

Ринок: **Україна / Харків (UA) — основний**, **ЄС (EN) — вторинний**.
Принцип: **один головний ключ на сторінку**, без канібалізації. Джерело правди для title/description — `scripts/pages.json`.
Частотність не вимірювалась (немає доступу до Google Keyword Planner / Serpstat у нічній сесії) — кластери зібрані за інтентом. Рекомендую перевірити частотність у Keyword Planner (акаунт Google Ads уже є) і підкоригувати.

## Додаткові (вторинні) ключі по кластерах

**Розробка сайтів** → `/services/websites/`: розробка сайтів, створення сайту під ключ, замовити сайт, веб-студія, розробка сайту для бізнесу, сайт для компанії.
**Ціни** → `/pricing/`: скільки коштує розробити сайт, ціна сайту, вартість розробки сайту, ціна лендингу, скільки коштує інтернет-магазин, скільки коштує телеграм бот.
**Лендінг** → `/services/websites-landing/`: створення лендингу, лендінг під ключ, landing page, односторінковий сайт, лендінг під рекламу.
**Інтернет-магазин** → `/services/websites-shop/`: інтернет-магазин під ключ, створення інтернет-магазину, розробка інтернет-магазину, магазин з оплатою LiqPay / Нова Пошта.
**Корпоративний сайт** → `/services/websites-corporate/`: корпоративний сайт, сайт компанії, багатомовний сайт, B2B сайт.
**Харків** → `/services/websites-kharkiv/`: розробка сайту Харків, створення сайтів Харків, веб-студія Харків (головна теж бере брендовий «веб-студія Харків» — головна = бренд+загальне, ця сторінка = локальний комерційний інтент).
**Telegram-боти** → `/services/bots/`: розробка телеграм бота, створення телеграм бота, телеграм бот для бізнесу (інформаційний варіант → блог), чат-бот telegram.
**Таргет** → `/services/meta-ads/`: таргетована реклама, таргет, налаштування таргетованої реклами, реклама у Facebook. Instagram-інтент → `/services/meta-ads-instagram/`.
**Google Ads** → `/services/google-ads/`: налаштування Google Ads, ведення Google Ads, Google реклама. Пошуковий інтент («контекстна реклама», «реклама в пошуку Google») → `/services/google-ads-search/`.
**SEO** → `/services/seo/`: SEO просування, просування сайту в Google, розкрутка сайту. Аудит → `/services/seo-audit/` (комерційний) vs `/blog/seo-audit-shcho-tse/` (інформаційний «що таке»). Локальне → `/services/seo-local/`.
**EN** → `/en/services/websites/`: website development Ukraine, web development company Ukraine, hire Ukrainian web developers. `/en/pricing/`: custom website development cost, how much does a website cost, website price Ukraine.

## Розведення можливої канібалізації
- `/pricing/` (комерційний: «наші ціни») ↔ `/blog/skilky-koshtuye-sayt-2026/` (інформаційний: «ринкові ціни 2026»). Блог перейменовано на «Ціни на сайти у 2026: ринкові вилки» і він посилається на `/pricing/`.
- `/services/websites-kharkiv/` ↔ `/blog/zamovyty-sayt-kharkiv/`. Блог переорієнтовано на «як вибрати веб-студію» (чек-лист).
- `/services/google-ads/` (усі формати + ведення) ↔ `/services/google-ads-search/` (лише пошук).
- `/services/meta-ads/` (Facebook + Instagram) ↔ `/services/meta-ads-instagram/` (лише Instagram-формати).

## Аналіз видачі конкурентів (веб-пошук, 2026-10-29)
Запити: «розробка сайтів під ключ Харків ціна», «скільки коштує розробити сайт 2026», «розробка телеграм бота ціна під ключ», «custom website development cost Ukraine agency».
- У топі домінують: блоги студій з таблицями цін (webscraft.org — гід «Сайт під ключ в Україні: скільки коштує», ціни в гривнях з розбивкою за типами), OLX-оголошення фрилансерів (від 2 500–4 000 грн), агрегатори (Clutch, DesignRush) для EN.
- Що відповідають конкуренти: вилки цін за типами сайту, що входить у пакет (дизайн, CMS, базове SEO, аналітика, навчання, 1–3 міс. підтримки), терміни 14–21 день, поради «шаблон vs розробка».
- EN-видача: Clutch/DesignRush-рейтинги + сторінки студій з тарифами ($600 / $1 500 / $3 500 тири, 7–30+ днів).
- Висновки, застосовані на сайті: окрема сторінка цін з таблицею по всіх послугах, блок «що входить / що не входить», терміни на кожній сторінці, FAQ з цінами.
- Ідеї на потім: дублювати ціни в гривнях (за курсом НБУ, з поміткою «орієнтовно»); профіль на Clutch/GoodFirms для EN-видачі.
